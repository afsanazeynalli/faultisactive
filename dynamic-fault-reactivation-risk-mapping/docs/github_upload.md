# GitHub upload guide

1. Create an empty repository named `dynamic-fault-reactivation-risk-mapping`.
2. Choose public or private based on your data and publication plan. This starter contains only synthetic sample data.
3. Extract the ZIP and upload its contents to the repository root with **Add file → Upload files**, or copy them into a local clone and commit.
4. Review the rendered README, especially the stated scope and limitations.

Suggested description: `Research starter for uncertainty-aware fault stability screening during fluid injection`

Suggested topics: `geomechanics`, `poromechanics`, `fault-reactivation`, `uncertainty-quantification`, `research-software`

Before public release, replace the generic author in `CITATION.cff`, confirm references and novelty against publisher records and a documented literature/patent search, check data/software licensing, and decide whether MIT remains appropriate. MIT covers this starter code only, not external datasets or papers. Avoid committing proprietary field data.
